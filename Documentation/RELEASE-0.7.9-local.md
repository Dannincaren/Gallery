# Gallery 0.7.9 本地更新

2026-10-30，build 20。用户已确认最终预览并要求打包；仅本地交付。

- 主题子页面的 gallery 标题采用已确认的哥特字体，与目录保持一致。
- 单击未选中的非活动主题先选中，再次点击已选中或正在使用的主题进入子页面。
- 选择状态使用轻微灰色底托，正在使用的主题使用更明显的底托和奶白柔光字样；标准黑体字形横画左低右高，封面始终静态。
- 底托过渡约 0.2 秒。启用后等底托展开完成再淡入文字；停用时文字柔和淡出，随后收回底托。快速切换会撤销旧的后续显示动作。
- 右上角停用时显示开始，运行时显示停止；选择其他未使用主题后从最左侧追加开始。胶囊右边缘固定，先展开再出现图标，先淡出图标再收回，不再因原生工具栏增删项目而整体重排。macOS 26 使用玻璃外观，macOS 14/15 使用材质胶囊。
- 主题切换只保存必要的修改，并使用受文件变更校验的有界读取缓存；选择时按需预读。归档重复图片只哈希一次，文件内容与原编码保持一致。
- 加载提示延迟出现于右上角，不参与目录布局，不再使整片目录变暗。

验证：54 项核心检查通过；真实 示例光标主题／另一个示例主题 归档字节一致、外部替换和删除缓存失效、未保存编辑跨主题保留检查通过。隔离界面实际核对三种按钮状态、顺序和胶囊展开／收回后的右侧对齐；用户确认最终效果无问题。原有光标播放架构保持不变，未重复启动系统光标诊断。

本地导航对照中四次切换合计约 795→105ms，只代表该隔离模型与素材，不是所有机器的端到端承诺。所有新增过渡仅在操作时运行，主题卡片没有常驻动画。

macOS 14+，包含 arm64 与 x86_64；采用临时签名，未做 Developer ID 公证。字体、导入助手和第三方许可完整保留，本地保留符号文件。未在 Intel 实机运行。
