# Gallery 0.5.3 预览版

本版收尾文字选择光标在移动时重播、闪烁的问题。Finder 文件夹拖放松手的偶发抽动按用户要求暂缓，尚未宣称解决。

## 文字动画

- 前台应用重新选择文字光标时，系统注册项同步为当前静态动画帧，避免再次从原生循环首帧播放。
- 注册光标和 AppKit 缓存光标使用相同的多分辨率图像及热点，避免两种采样方式交接；只提交当前显示器需要的分辨率。
- 常用文字动画的资源在启用时预热。正常播放复用有界缓存，不逐帧重新编码图片。
- 短暂的文字→箭头→文字区域重建保留循环进度；点击和暂停重新开始对应周期。

## 输入与帧交接

- 鼠标监听和系统输入计数互相核对，移除每次点击后多余的两秒高频轮询。
- 动画使用相位对齐的截止时间，避免相对定时累积误差；确认图像后立即追赶期间到达的按下或松手。
- 自身图像编号按完整角色、动作、图像和大小判断，历史帧只提供恢复线索，不等于当前帧。
- 保留拖放入口同步与已显示松手进度的接续措施，但真实 Finder 文件夹拖放仍有偶发抽动；相关本地诊断已留存，后续继续。

## 验证与开销

39 项核心检查通过，含真实 示例光标主题 提取、动画时序、输入计数去重、短暂区域重建的循环时钟。实际 WindowServer 回归覆盖旧帧恢复、角色大小隔离、资源还原，以及文字角色反复重选。

文字图像同步增加了持续动画时的开销。本机受控短测约 8–9% 自进程 CPU，静态约 0.5%；数值不包含 WindowServer 或整机耗电，仍有优化空间。优先完成文字交接修复，性能与 Finder 剩余问题留待后续。

更新后重新应用原有主题即可，无需重新导入。macOS 14+，临时签名、未公证，继续遵守 Mousecape 非商业许可，不附带 示例光标主题 素材。
