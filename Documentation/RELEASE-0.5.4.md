# Gallery 0.5.4 预览版

改善 Chrome、ChatGPT 桌面端等第三方应用中的文字光标闪烁，新增同角色素材版本切换，并整理交互设置界面。

## 文字与系统场景

- 文字动画更新当前注册帧时保留系统文字光标身份，去掉每帧额外的自定义 NSCursor 提交；按下、按住和松手也使用同一路径。
- Dock 点按仅在手势期间启用对应光标提交支持；调度中心的常态仍为静态，点按阶段可播放动画。停用和交互结束后清理临时设置。
- 本轮用户实测确认第三方应用的文字闪烁改善，以及 Dock、调度中心点按动画可用。
- Chrome 地址栏点按后显示箭头仍未解决。测试期间全局光标可能受诊断程序影响，不能据此确认系统或 Chrome 的责任；按用户要求暂缓，移除无效的角色保持试验。
- Finder 文件夹拖放松手的偶发抽动仍按此前要求搁置。

## 编辑器与素材

- 待机设置改为分组布局，滑块旁保留单行数值和单位，移除重复标题及意外换行。
- 示例光标主题 导入保留同一角色的静态、动态等备选素材，暂停后可在动作页的「素材版本」中切换。
- 可添加另一套 PNG、GIF、CUR、ANI。切换会保存离开版本的热点、帧序等编辑；各版本随 `.gallery` 导出，图片共享去重。
- 旧主题仍可打开；旧归档没有保存的备选素材需重新导入原安装包或手工补充。本项目不分发 示例光标主题 图片。

## 验证与边界

40 项核心检查通过，含真实 示例光标主题 静态／动态提取、版本切换保留编辑、旧格式兼容和独立归档。编辑器回归覆盖角色别名同步、其他角色隔离与保存，深浅色设置界面已检查。

实际系统回归覆盖文字反复重选、角色大小隔离、帧确认与恢复、调度中心交互状态。受控短测静态约 0.42% 自进程 CPU，持续文字动画约 8.06%；不包含 WindowServer 或整机能耗，不能代表所有应用。此回归测量包含后来已撤除的地址栏角色保持试验；最终包未重新运行会修改全局光标的测试，以避免干扰用户原生光标对照。

macOS 14+，临时签名、未公证，继续遵守 Mousecape 非商业许可。更新应用后重新应用主题即可；要补全旧 示例光标主题 主题的素材选项，请重新导入原文件。
