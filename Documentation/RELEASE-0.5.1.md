# Gallery 0.5.1 预览版

本版修复重新打开窗口后 Dock 图标不再隐藏、离开窗口边缘后调整光标残留，并加入角色独立待机时间与可输入数值的滑块。

## 修复

- 在窗口重新打开、激活、关闭等事件后重新核对 Dock 隐藏策略，并在窗口创建事务结束后做一次合并校正。没有增加后台轮询。
- 高分辨率系统箭头可能返回 280×400 等物理像素尺寸；移除把 128 逻辑点限制误用于这种位图的判断，恢复普通箭头识别。
- 自身光标种子的历史命中不再直接视为当前角色所有权，避免旧角色的缓存种子干扰切换；过时角色的异步识别结果会被丢弃。
- Gallery 右下边角的保持范围从 12 点缩短到 7 点，退出时不再要求同时远离两条边，减少调整角色残留。

## 待机与控件

- 每个角色的「待机」页提供「跟随全局 / 单独设置」。全局默认仍保留，旧主题自动沿用原设置。
- 独立等待时间使用原有状态机和一次性定时器，只保存、比较一个数值，不为每个角色创建计时器。
- 等待滑条快速调整 1–60 秒，输入框支持 1–600 秒；恢复「跟随全局」会移除当前角色的覆盖值。
- 全局大小、角色大小、全局等待和角色等待均配数值输入框。回车或移开焦点确认；未改动的输入不会重复保存。
- 滑条移除密集刻度，使用蓝色连续轨道和圆角数值框。角色的独立设置集中在待机页。

## 能耗与流畅性

- 预计算连续重复帧的区间，只在图像真正变化时提交，保留每帧原来的停留时间和循环时长。
- 单纯移动鼠标不再维持 120Hz 渲染计时器；角色变化由事件立即触发观察，鼠标位置仍由系统管理。无法监听时保留输入采样回退。
- 单次动画预览到结尾后停止刷新；相同数值不再重复写入偏好或安排主题保存。

## 验证

34 项本地核心检查通过，含真实 PRTS、320 像素静态识别、角色待机归档与旧主题兼容、重复帧循环时序。编辑器检查覆盖独立等待的别名同步、保存和恢复全局默认。

实际系统光标检查通过 300 次快速角色切换、重复帧不重复提交、1,000 次移动观察不触发高频渲染、角色等待时间，以及水平 / 垂直 / 对角调整切回高分辨率系统箭头。结束后正常恢复备份。

实际界面检查通过手输大小、角色独立等待、切换角色保留数值、恢复全局默认，以及启用隐藏 Dock 选项后关闭并再次打开窗口仍保持隐藏。

同机短时测量中，PRTS 文字多帧常态 CPU 由基线约 4.16% 降至约 1.8–3.1%；静态约 0.15–0.56%。这不是整机耗电或所有应用的固定保证，见 [性能记录](PERFORMANCE.md)。

退出旧版后替换应用即可，不必重新导入主题。角色待机设置随 `.gallery` 保存；`.cape` 仍仅导出常态资源。

macOS 14+，Universal（Apple Silicon 与 Intel），临时签名、未公证。继续使用 Mousecape 的非商业许可，PRTS 素材不随源码或应用分发。
