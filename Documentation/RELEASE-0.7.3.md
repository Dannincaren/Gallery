# Gallery 0.7.3 预览版

主题目录增加持久化自定义排序和自选封面，标题采用已确认的 A 款哥特字体。

- 点击「调整顺序」后直接拖动卡片，其他卡片实时让位，拖动浮层只显示缩略标签；卡片菜单也支持向前／向后移动、置顶和放到最后。无需额外手柄，封面保持完整。松手才保存顺序；取消拖动或拖出窗口恢复原位。完成排序后恢复打开主题的操作。搜索时暂停拖拽，避免筛选后的目标位置产生歧义。
- 顺序保存在现有本机索引中，重启后保留。新主题追加到末尾，原有目录顺序保留；排序只写索引，不启用或重载主题、不改变编辑内容和大小，也没有动画轮询。写盘失败时提示并恢复顺序。
- 帧序列新增「设为主题封面」，保存当前帧的静态快照；支持恢复默认箭头封面，封面随 Gallery 主题导入导出，源帧删除后仍可保留。帧编辑用词统一为「当前帧」。
- Gallery 字标使用 UnifrakturMaguntia，随应用附带未修改字体及 OFL1.1 许可，只向当前进程注册。

验证：47项核心检查通过（含用户提供的示例光标主题 1.1.5安装包、第三方示例；CI无第三方素材时45项）。编辑器独立目录检查通过，新增排序方向、重启、归档字节不变、延迟保存、导入追加与写盘错误回退的回归。

已离线检查用户提供的 示例光标主题-Setup.exe：没有发现箭头松手素材损坏或整段重播，重新提取的主要素材与此前导入一致。源素材存在跨阶段共享画面，抽动仍需继续诊断，详见 [资源检查](RESOURCE-AUDIT.md)。本版沿用0.7.2光标运行层，不包含此前实测变差的候选锁或注册实验。

macOS14+，现有许可、权限与临时签名方式不变。第三方鼠标主题和安装器不随项目分发。
