# Gallery 0.5.0 预览版

本版重构运行层，优先解决快速移动不跟手、Dock 闪回、角色切换后光标消失及全屏空间切换时覆盖窗口漂移的问题。

## 系统光标与动画

- 常态继续通过 Mousecape 的注册路径写入系统资源，补充可读取、备份的 ArrowS / IBeamS 兼容别名。
- 命中注册的静态资源时直接使用系统光标；前台应用的旧缓存未更新时，使用缓存的 NSCursor 图像补足。
- 移除隐藏系统光标和跟随鼠标的覆盖窗口。位置、可见性和 Spaces 合成始终由 macOS 管理。
- 点按、待机及多帧常态仍可播放：预解码帧通过系统光标通道提交，最多每秒 60 次；静止单帧约每秒 5 次保底检查，不逐帧解码 PNG。
- 使用输入事件原始时间，松手立即抢占按住；迟到的按下不会补播过时按住。系统别名变化不重启动画。
- 自身提交的光标种子在观察前、异步结果返回后各过滤一次，避免把自己的动画帧误认为另一角色。
- 调度中心使用主题常态第一帧，退出时直接恢复普通路径；没有额外的隐藏窗口、覆盖窗口空间移动或数秒恢复等待。

## 编辑与设置

- 独立大小、混搭与编辑按明确的角色族标识分组，重名不会把水平、垂直、链接等角色绑定在一起。大小滑块固定操作创建它的角色，避免选择变化后修改另一项。
- Gallery 右下角增加进入 / 退出阈值，避免调整大小与正常选择在边界频繁切换。
- 增加「启用主题时隐藏 Dock 图标」选项。隐藏后从菜单栏打开 Gallery，停用主题后恢复 Dock 图标，默认关闭。
- 增加「快速甩动鼠标时放大主题光标」选项，默认关闭。连续快速往返才触发，随后自动恢复；系统本身的定位鼠标设置独立生效。
- 自定义主题启用期间，禁用编辑器播放 / 重播按钮并说明预览已暂停。单帧同样禁用播放。
- 角色列表恢复缩略图：后台生成最大 64 像素的 PNG，保存到目录索引并复用缓存；不在列表里实时播放或解码整套动画。

## 验证与边界

31 项核心检查通过，含真实 PRTS、输入时序、大小分组、边角阈值、甩动识别及缩略图兼容。编辑器检查通过旧主题迁移、多目录、复制帧、重名角色大小隔离和混搭保存。

实际界面核对通过新增开关显示、启用主题时禁用预览、停用后恢复预览，以及原生菜单的全屏进入 / 退出。验证结束已停用主题并正常退出。

实际系统光标回归通过三种图像帧、300 次角色切换的可见性及几何检查，以及运行层点按、异步自身帧过滤、静态唤醒和停用恢复。调度中心模式的进入 / 退出采用状态注入检查；本次没有自动执行真实三指全屏手势，仍需在使用机器上复测这些手势及 Dock 长时间悬停。私有接口、前台程序自己的光标隐藏和不同系统版本仍可能影响表现。

同机本轮测得静止箭头约 0.45% 自进程 CPU、4 秒内 19 次检查；PRTS 文字选择多帧常态约 4.09%。这是短时回归数据，不是整机能耗或所有环境的固定保证，见 [性能记录](PERFORMANCE.md)。

退出旧版后替换应用。原有主题和设置可继续使用，无需重新导入。更改动画或来源后暂停再应用；全局与单角色大小可直接调节。

macOS 14+，Universal 应用（Apple Silicon 与 Intel）。使用临时签名，尚未签名公证。保留 Mousecape 非商业许可，PRTS 素材不随应用或源码分发。
