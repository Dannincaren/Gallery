# Gallery 0.6.0 预览版

新增整套主题删除、清晰的主题切换，以及通用 Windows 光标安装包导入。

## 主题管理

- 主题名称上方的垃圾桶、目录右键菜单和工具栏主题菜单均可删除整个主题。确认后将 `.gallery` 文件移入废纸篓，原始素材不受影响。
- 删除正在使用的主题时先停用并恢复光标；删除最后一套时回到内置示例。删除前保存待处理编辑，阻止旧的保存及缩略图回调恢复已删目录。文件或目录写入失败时尝试还原。
- 目录分别显示「正在使用」「浏览中」，顶部持续显示当前实际主题名称。浏览角色不改变实际光标；目录「使用」和工具栏「切换到此主题」负责启用。
- 开启启动后自动应用时优先使用上次成功应用的主题，避免仅浏览其他目录便改变下次启动的主题。退出会等待导入或删除操作完成。

## EXE、文件夹、INF 与 ZIP

- 支持读取内嵌 CUR／ANI 的 .NET EXE，不限于 PRTS 的特定命名。读取内嵌 INF 的角色与字符串声明，保留动画、热点和备选素材。
- 可选择或拖入整套素材文件夹，也可选择其中的 INF，或导入含 CUR／ANI 和 INF 的 ZIP。
- INF 的角色映射优先；没有配置时识别 pointer、text、horz、vert、dgn1／dgn2 等名称。未匹配文件保留为可编辑、可混用素材。
- 全程不执行安装器或 INF 指令。不同封装方式无法保证全部支持；无法解析时明确提示使用解压后的光标素材。素材本身没有点按或待机片段时不会生成新动画。

## 验证

43 项本地核心检查通过，含真实 PRTS，以及用户示例 EXE 的全部17个ANI、对应ZIP、解压文件夹和直接INF导入；逐项核对帧序、热点、尺寸、时长与独立归档。另覆盖无INF命名、INF映射优先、未知素材保留和过长字符串拒绝。

独立编辑器目录验证删除其他主题、删除最后一套、删除前保存、延迟保存不复活目录及移入废纸篓失败；测试使用隔离的回收目录，不删除用户主题。此次没有修改光标渲染或新增权限，也未重启跨应用诊断。Chrome地址栏和Finder拖放遗留问题继续保留。
