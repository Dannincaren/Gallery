# Gallery 0.3.0 预览版

修复原生箭头、文本选择与后台动画的显示路径，补全光标切换后的恢复；增加大小和启动设置。

## 更新

- 添加白底、黑色居中指针符号的应用图标，供 Dock、Finder 与应用切换器使用。
- 修复系统光标识别只保留最高分辨率的问题，保留 1x、2x 等所有位图，避免原生箭头和文字指针无法触发动画。
- 正确读取 WindowServer 返回的完整动画条带，联合首、中、尾帧识别角色。水平调整等动画指针不再导致识别停留在上一状态。
- 原生系统保留旧箭头或文字图像时，通过不激活、不接收点击的显示层提供常态主题。未知自绘光标会交还给应用，返回已知角色后恢复。
- 补上 CoreCursor 1 文本状态；示例光标主题 主题现含 20 类、46 个资源变体。
- 交换两个对角调整状态的素材映射。请重新导入新版 示例光标主题 主题，或重新导入原安装包，以更新已有主题中的方向素材。
- 主界面加入 50%–300% 大小滑块与还原按钮，尺寸和热点同步变化。仅缩放 Gallery 主题，不修改系统辅助功能的指针大小；未知自定义光标保持自身尺寸。单个指针最大为 128 逻辑点。
- 设置中增加登录后自启动、启动后应用当前主题两个独立选项。默认关闭，使用系统 SMAppService 登录项；需要时显示系统批准入口。存在恢复记录时不会自动应用。

## 使用

先退出旧版，将新版 Gallery 放入「应用程序」后打开。导入更新后的 `.gallery` 主题，点击「应用主题」。
「指针大小」滑块可在启用时使用；「交互与应用设置」中可开启登录后自启动，以及启动后自动应用主题。
本版为 macOS 14+ 的 Universal 应用，包含 Intel 与 Apple Silicon 架构，使用临时签名，尚未签名公证。

## 验证与边界

19 项本地检查通过，包含真实 示例光标主题 提取、动画条带识别、大小与热点、旧主题兼容等。
独立前台进程使用原生 NSCursor 的桌面回归验证了：箭头与文字主题显示、后台按住/松手、待机退出、水平调整、未知→已知恢复、150% 大小和自定义光标尺寸保留，以及停用恢复。
测试向 Gallery 状态机提供点击边沿；实际系统鼠标监听回退另有计数检查。测试窗口的结果不等于所有应用兼容。

尚未实测所有浏览器、游戏、多显示器及系统登录流程。自启动需要用户在稳定安装位置开启，并可能需要在系统设置中批准。
独占游戏、自绘光标、安全界面和系统版本差异仍可能限制效果。出现异常可通过菜单栏「停用并恢复」。
示例光标主题 和游戏素材不随应用或源码分发。
