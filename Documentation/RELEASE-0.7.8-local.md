# Gallery 0.7.8 本地更新

2026-10-30，build 19。仅本地交付，未上传 GitHub。

- 所有导入素材版本的预览按钮统一使用查看图标。
- 实时帧直接使用预解码位图，只生成当前显示器需要的分辨率，去除 PNG 编解码往返；文件导出继续保留完整分辨率。
- 预热点按中不同的画面，重复帧不再占用预热名额；缓存角色别名分组及短期 Dock 窗口判断，减少首次准备与重复点击开销。
- 识别图像时直接写入已有采样缓冲区，消除每帧数百个临时小数组；识别规则与结果保持一致。
- 导入、设置等模态窗口覆盖编辑器时，暂停底层编辑器的预览动画。
- 发布副本剥离调试符号；本地保留原始二进制与匹配的 dSYM。不删除架构、字体或导入支持，维持原优化级别、动画时序、轮询频率与画面确认机制。

54 项核心检查、系统光标回归、新旧位图逐像素对照和识别指纹一致性检查通过。用户现场复测没有发现明显问题。

测量范围、耗时、CPU 与包体积见 [性能验证记录](PERFORMANCE-0.7.8.md)。CPU 是同机短时对照，不等同电池功率；帧准备耗时不等于完整输入到屏幕显示延迟。
