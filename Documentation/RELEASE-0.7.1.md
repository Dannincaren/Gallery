# Gallery 0.7.1 预览版

修复部分 Windows 素材被误判为无效 ANI，以及 24 位光标导入后出现黑底的问题；主题橱窗标题改为已确认的古典手稿花体。

## 导入

- 兼容 ANI 导出器将 RIFF 长度误写为整个文件大小的情况（比标准值多 8 字节）。仅接受这一种精确误差，继续检查每个区块和帧的实际边界，拒绝其他长度不符及截断。
- 24 位 CUR／ANI 按原位图的行对齐、上下方向及 AND 遮罩解码，保留透明背景；32 位带 alpha 的素材沿用原行为。
- 整套导入失败时显示具体素材名，便于定位损坏文件。文件夹、INF、ZIP 和支持的 EXE 共用此解码路径，不执行安装器。

## 界面

主题目录的 Gallery 标题使用系统 Zapfino 花体，按 A／B／C 预览中确认的 C 方案实现。其余目录、卡片菜单和编辑操作保持一致；没有新增字体下载、常驻刷新或动画。

46 项本地核心检查通过，包含真实 示例光标主题 与 第三方示例。第三方示例 的 13 个 ANI 均已读取，帧、热点、尺寸、时长和归档往返核对通过；另验证 24 位透明遮罩和异常文件拒绝。CI 使用自造数据运行 44 项检查，不附带第三方主题或字体文件。

沿用 macOS 14+、现有许可与临时签名方式。本轮不修改系统光标运行路径，Chrome 地址栏和 Finder 拖放遗留问题保持原状。
