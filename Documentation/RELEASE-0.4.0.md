# Gallery 0.4.0 预览版

本版集中改善 CPU、点按响应、复杂界面的移动跟随及大小调节，并加入主题目录和单角色设置。

## 运行体验

- 移除鼠标热路径中的 PNG 编码、解码与主线程图像识别；启用时预解码帧，识别移至单个后台工作线程，使用有界缓存。
- 点按直接切换已准备好的帧；鼠标事件不再等待一次完整识别。无监听权限时使用 120 Hz 计数回退。
- 角色之间共用同一被动图层，避免频繁显示/隐藏系统光标。位置和图像更新分离，静态帧跳过重复提交。
- Dock 覆盖控制及可见性核对，防止原生和自定义光标持续叠加；恢复请求保持成对，无法确认隐藏时不叠画。
- 全局和单角色大小立即变换尺寸及热点，不重建图片或重新注册整套角色；各滑块范围 50%–300%，组合后最大 128 逻辑点。
- 静态帧、应用后台、隐藏/最小化窗口或应用主题期间，停止无用的编辑器预览刷新。缩略图复用缓存并延迟显示。

## 编辑和主题管理

- 导入的每个主题各自保存为目录，点击展开角色。导入新主题不覆盖已有主题；浏览另一个目录不会自动切换运行中的主题。
- 旧版当前主题自动迁入目录，无需重新导入。
- 每个角色可选择「使用系统原有光标」，不再应用该角色的自定义图像、动画和大小。
- 「从其他主题选取」复制角色的全部动画，保留目标角色的用途及独立大小。混搭素材完整保存在当前主题中，不依赖来源目录。
- 帧序列增加「复制当前帧」与右键复制，副本放在原帧之后，最多 240 帧。
- 自动保存移至工作队列，退出时等待保存完成；目录切换和新导入保留之前的编辑。

## 性能和验证

同机、同一原生测试窗口，使用相同 PRTS 主题进行对比：

| 指标 | 0.3.0 | 0.4.0 |
|---|---:|---:|
| 静止后台进程 CPU | 8.9% | 4.9% |
| 连续切换角色 CPU | 18.7% | 9.8% |
| 点按处理耗时 p95 | 0.97 毫秒 | 0.41 毫秒 |
| 连续五次大小更新总耗时 | 4862 毫秒 | 1.95 毫秒 |

CPU 是自进程用户/系统时间与墙钟时间之比。点按耗时是处理函数到提交显示帧，
不包含系统输入采样和屏幕刷新。数据不代表所有机器或所有应用的固定 CPU；方法见[性能记录](PERFORMANCE.md)。

24 项本地核心检查通过（含真实 PRTS），编辑器检查通过旧主题迁移、多目录、复制帧及混搭保存。
独立前台原生窗口的后台回归通过点按、待机、水平调整、未知恢复、全局/角色大小、快速连续角色切换、热点跟随、Dock 悬停、原生角色及停用恢复。
测试没有向其他应用注入点击；Dock 测试只移动指针，完成后恢复位置。

## 使用

退出旧版，将新版放入「应用程序」后打开。旧主题会自动出现在目录中；大小设置可直接调整。
更换角色来源或编辑帧时先暂停，完成后重新应用。

macOS 14+，Universal 应用，包含 Intel 与 Apple Silicon。使用临时签名，尚未签名公证。
私有接口、独占游戏、自绘光标、安全界面、显示器配置及系统版本仍可能影响体验。
PRTS 和游戏素材不随应用或源码分发。
