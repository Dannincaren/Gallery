# Gallery 0.7.7 本地更新

2026-10-30，build 18。仅本地交付，未上传 GitHub。

- 导入多素材版本时，每份素材旁新增「预览」按钮；静态与动态版本均可查看。
- 预览独立于勾选框，浏览不会改变导入选择；未勾选的套装也能展开并查看素材。
- 一次最多打开一个预览弹窗。动态素材支持暂停、继续与重播；静态素材不创建动画时间线。
- 动画最高以 30 fps 预览，按源时间计算帧索引以保持原始速度与时长。此限制只作用于导入预览。
- 仅在弹窗打开且应用在前台时解码和更新；后台解码缩略图不超过 384 像素，局部帧缓存最多 16 张／4 MiB，关闭即清理。
- 带编辑的默认版本按当前有效素材预览，避免展示归档中未同步的旧版本。

本次只修改导入预览界面，不改动系统光标播放或导入选择保存逻辑。Apple Silicon 与 Intel Release 构建及打包签名检查见本地构建记录。
