# Gallery 0.7.8 性能验证

2026-10-30。本机、示例光标主题 复制主题、Release 优化编译；不写入用户主题库。数字用于比较本次优化，不能视为所有设备的固定表现。

## 未缓存的帧准备

同一测试进程配置，各场景各 12 次。只注册进程私有且从不显示的资源，测量后确认当前系统光标种子未改变。

| 场景 | 优化前中位数 | 去除 PNG 往返后中位数 | 准备阶段进程 CPU 时间（前 → 后） |
|---|---:|---:|---:|
| cold-press-first | 2.33 ms | 0.36 ms | 2.21 → 0.25 ms |
| press-all | 149.42 ms | 18.81 ms | 132.30 → 13.50 ms |
| normal-all | 158.88 ms | 17.65 ms | 138.21 → 13.80 ms |

这里测的是准备待提交资源的耗时，不包含 macOS 输入投递、WindowServer 合成和显示器刷新。首个常用点按画面本来就会预热；改进主要减少未命中缓存、调整尺寸后的首击，以及点按后续画面的等待。

## 运行场景

同一隔离运行程序，各场景测量 3 秒。记录进程 CPU（不含 WindowServer），另报告每秒 tick 与提交数；程序含同样的内存诊断记录，不进行逐帧写盘。移动为每秒约 120 次调用输入处理，不向系统注入事件。

| 场景 | CPU 前 → 后 | 唤醒前 → 后（次/秒） | 提交前 → 后（次/秒） |
|---|---:|---:|---:|
| static | 0.87% → 0.82% | 5.0 → 4.9 | 0.0 → 0.0 |
| animated-text | 8.06% → 6.29% | 87.8 → 87.8 | 28.7 → 28.7 |
| animated-text-120-moves | 9.60% → 7.91% | 80.7 → 80.3 | 32.7 → 32.7 |

没有提升后台轮询频率、改变动画帧率或取消画面确认。CPU 是短时对照，不能等同电池功率或保证固定下降比例。

## 正确性

- 示例光标主题／另一个示例主题 共 42 组新旧画面逐像素对照，通道最大差值为 0。
- 86 个 示例光标主题 图像表示的新旧识别指纹 Hashable 值及几何信息一致；2000 次指纹构建约 78.8 → 27.4 ms。
- 54 项核心检查通过，包括帧序、缩放、图像边界、输入时序及资源恢复相关模型。
- 系统光标回归通过：11 个角色的常态／点按，大小调整、静态文字版本点按、阴影、原生循环身份和恢复。

## 发布体积

仅在发布副本上执行 strip -S -x；保留导出符号，原始二进制及 dSYM 留在本地。原始同版导出符号列表与剥离副本一致。优化级别维持 -O，不改为 -Osize，也不删除功能、架构、字体或素材格式支持。


最终包体积（十进制 MB）：应用内容 10.75 → 5.13 MB；ZIP 2.96 → 2.22 MB。优化后原始构建与剥离副本的 82 个运行时节逐字节一致，导出符号列表一致，arm64/x86_64 的 dSYM UUID 与应用一致。签名及解压后复验通过；剥离后的 Inno 助手成功启动并输出版本。

最终用户现场反馈：示例光标主题 文字／链接移动、点按及拖动松手「没发现明显问题」。验证实例已正常停用退出，独立恢复记录已清除。
