# Gallery 0.5.2 预览版

本版针对调整光标滞留、跨角色松手抽动、甩动缩放和链接交互进行修正。

## 调整角色与识别

- 已被系统正确选择的注册调整常态（含动画）交由原生光标播放，不再由 Gallery 重复逐帧提交。系统注册仍为最多 24 帧的等时采样，保留总时长；缓存旧图像、交互及临时缩放仍有实时路径。
- 提交后若系统尚未发布新编号，不再把原来的前台光标编号记成 Gallery 所有；后台读取实际图像确认后再记录归属。只在等待确认期间短暂重试，沿用现有观察队列。
- 异步结果只有在对应的系统编号仍为当前资源时才可应用，新的 Gallery 帧不会让旧的外部识别结果重新有效。
- 注册图像匹配与选中的角色关联，拖放别名与普通箭头/手形图像相同时优先主要角色，避免沿用先前的正常选择。

## 点击与按住

- 同一点击在拖放、聚焦导致角色变化时保留当前阶段和开始时间；松手动画不会因角色切换从头播放。
- 丢弃迟到的重复按下和松开事件，避免一次物理松手重复进入松手动画。
- 移除「拆分按下、按住与松手」开关。有按住素材就持续到松手，未添加按住素材就自动连播按下与松手。旧主题中保存的开关不再覆盖素材行为；旧归档可直接读取。

## 甩动放大

- 一次手势仅启动一轮缩放，放大及收尾阶段的剩余反转不会再次触发放大。
- 放大与缩小使用缓动曲线；变化阶段按 60Hz 调度，停留阶段直接等待缩小开始，回到正常大小后停止该调度。

## 验证与边界

36 项核心检查通过，包含真实 PRTS、自动按住与旧开关迁移、相同拖放图像优先级，以及缩小曲线连续单调。

系统运行检查通过实际三色图像、300 次快速切换、旧编号不被误认及图像确认、注册调整常态零重复提交、过时调整结果不覆盖新光标、仅移动退出调整区域、4 个带按住素材的真实 PRTS 角色族，以及跨拖放/焦点角色变化保持一次松手。测试使用独立恢复记录，不注入系统输入。

这些是受控回归，不能代替每个应用的实际鼠标悬停、Finder 拖放和桌面弹窗验证。链接角色跟随应用给出的手形/可点击光标，不分析视频或聊天内容识别 URL；视频入口使用手形时同样会显示链接角色，应用给出箭头时仍显示正常选择。
