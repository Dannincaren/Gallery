# 性能记录

## 0.5.0：系统光标通道

2026-10-28，本地 macOS 27.2 / Apple Silicon，release 构建，PRTS 主题。旧版覆盖窗口已移除，
系统负责鼠标位置，程序只更新缓存图像帧。单帧常态采用系统注册资源或缓存 NSCursor，多帧和交互最多 60 次提交/秒。

`Scripts/runtime-check.sh` 当前使用自己的 AppKit 事件循环和独立恢复记录，不移动鼠标或注入 OS 输入。
CPU 为 getrusage 的进程用户及系统时间差 / 墙钟时间差；不包含 WindowServer、显示器或整机耗电。
预热后静态箭头采样 4 秒，PRTS 多帧文字常态采样 3 秒：

| 场景 | 自进程 CPU | 运行检查次数 |
|---|---:|---:|
| 静止箭头 | 0.45% | 4 秒 19 次 |
| 多帧文字常态 | 4.09% | 按动画帧率更新 |

以上是短时回归数值，不能作为所有应用的上限，也不与旧版不同测试程序构成严格功耗对照。
额外检查包括实际系统图像三帧切换、300 次角色切换中的可见性与大小、点按抢占、自身帧过滤及停用恢复。
调度中心模式以状态注入验证；本轮没有自动化真实三指滑动、锁屏或 Dock 长时间悬停。

复测：

```sh
bash Scripts/runtime-check.sh /tmp/gallery-runtime-new /path/to/PRTS.gallery
bash Scripts/editor-check.sh /tmp/gallery-editor-new
```

不要与正在运行的 Gallery 或其他光标工具并行检查。完成或失败后程序尝试恢复备份。

## 0.4.0 历史记录（旧覆盖窗口实现）

测量时间：2026-10-27。目的为检查同一机器上的回归与优化幅度，不设通用 CPU 保证。

## 方式

0.3.0 的运行层与当时的核心/原生桥单独编译，加入相同的基准循环；0.4.0 使用当前运行层。
均使用同一份 PRTS 主题、独立前台原生 NSCursor 测试窗口，以及后台控制器。
启动、主题转换和预热不计入测量；两个控制器均运行同样的 AppKit 事件循环。

- 静止：关闭待机，保持箭头 6 秒。
- 变化：45 次箭头、文字、水平调整切换，每次等待 40 毫秒。
- 点击：30 次直接向状态机提供按下/松手边沿，统计按下处理函数到提交显示帧的耗时。
- 大小：连续更新到 80%、100%、120%、150%、100%，统计总同步耗时。
- CPU：`getrusage(RUSAGE_SELF)` 的用户及系统 CPU 时间差 / 墙钟时间差 × 100。包含控制器自身工作线程和事件循环，不包含前台辅助进程或 WindowServer。

## 结果

| 指标 | 0.3.0 | 0.4.0 |
|---|---:|---:|
| 静止 CPU | 8.85% | 4.85% |
| 角色变化 CPU | 18.66% | 9.77% |
| 点按处理 p95 | 0.968 ms | 0.409 ms |
| 五次大小更新 | 4861.7 ms | 1.95 ms |

大小更新由重新生成并注册所有条带，变为当前图层的几何更新。因此这里比较的既是实现路径变化，
也是用户操作需要同步等待的时间。原生静态资源仍在启用主题时一次性注册；未知与原生角色不缩放。

点击数据不是设备输入到屏幕发光的端到端延迟。拒绝输入监控权限时，还存在最多约一个 120 Hz 采样周期的等待，
以及系统调度和显示器刷新时间。编辑器窗口可见时和其他复杂主题的 CPU 可能不同。

## 旧版复测方式（不适用于 0.5.0）

```sh
GALLERY_PERF_CHECK=1 GALLERY_FIXTURE_SYSTEM=1 bash Scripts/runtime-check.sh /tmp/gallery-perf /path/to/PRTS.gallery
GALLERY_DOCK_CHECK=1 GALLERY_FIXTURE_SYSTEM=1 bash Scripts/runtime-check.sh /tmp/gallery-dock /path/to/PRTS.gallery
bash Scripts/editor-check.sh /tmp/gallery-editor-new-directory
```

第一条输出 `PERF` 指标，第二条增加实际 Dock 悬停检查。普通桌面检查也覆盖 24 次快速角色变化及 18 次指针位置跟随。
它们会正常退出已运行的 Gallery，使用独立恢复记录并恢复原光标与位置；不要与另一光标工具同时运行。

编辑器检查只使用传入的新目录，不修改用户主题库或登录项。
