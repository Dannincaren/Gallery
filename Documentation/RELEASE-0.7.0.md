# Gallery 0.7.0 预览版

主题首页改为静态橱窗，点击卡片进入主题子页面，集中主题操作并简化工具栏。

## 橱窗与导航

- 主题按方形卡片排列，以各主题 arrow 的常态首帧作封面；始终静态，悬停也不播放。增加名称搜索和导入卡片。
- 点击卡片进入主题，左侧为角色列表，右侧保留全部动画、热点、大小、素材版本和帧编辑功能。顶部「主题橱窗」返回首页，编辑预览随页面退出。
- 正在使用的主题有清晰标记。打开主题不会自动应用；应用、暂停和恢复入口继续保留。
- Gallery 使用常规系统字体，移除标语。卡片菜单移到右下角；移除单独的资料库按钮，内置主题入口收进导入面板。

## 每主题操作

- 卡片右下角菜单和右键菜单共用打开、使用／停用、重命名、Gallery 导出、Mousecape 常态导出及整套删除。
- 子页面标题旁也有该主题的操作菜单；删除不再放在全局工具栏。确认面板显示主题名称，删除仍移入废纸篓。
- 未打开的主题可直接重命名或导出，保留当前浏览位置与动画内容。

## 缓存与验证

封面是单张最大192像素的PNG，写入本地索引并以图片摘要失效；旧主题在可见卡片需要时补齐。沿用有界图片缓存，卡片没有动画时钟或常驻刷新。没有arrow素材时使用中性占位，不以其他角色冒充。

43项本地核心检查通过（含真实PRTS）；新增封面角色选择、首帧、缓存复用／失效及旧索引升级。编辑器独立目录检查覆盖重命名、位置保留、动画／备选保留，以及此前的删除和保存回归。本轮原mon3tr安装器路径已不存在，未重复其可选集成检查；相关导入代码没有变化。

深浅色布局已渲染检查；隔离界面验证过进入主题、选择角色与素材版本、返回橱窗、菜单和取消删除。测试不启用自定义光标，不修改用户主题库或偏好。沿用macOS14+、Mousecape非商业许可、临时签名且未公证；不附带第三方主题图片。Chrome地址栏和Finder拖放遗留问题保持原状。
