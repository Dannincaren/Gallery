# Gallery 0.2.0 预览版

本版集中完善主题、编辑和导入体验；后台原生光标切换仍存在已知问题，尚未解决全应用兼容。

## 更新

- 每类指针增加「拆分按下、按住与松手」设置，仅箭头默认开启。关闭时点击后自动连播按下和松手，不等待抬起。
- 示例光标主题 导入扩充到 20 类、45 个资源变体，含帮助、链接、后台运行、忙、精准、移动、候选、水平/垂直/对角调整及不可用等。
- 手写、定位、人员选择保留为可编辑素材；macOS 没有对应的统一全局状态。
- 统一导入入口，可打开或拖入 `.gallery`、`.cape`、完整 Windows ZIP 或 `示例光标主题-Setup.exe`。导入仅提取资源，不执行 EXE。
- 热点、帧、显示大小与动画设置可在应用内编辑，别名同步修改；v2 主题去重保存并兼容旧主题。
- 加入后台鼠标监听与计数回退；未知光标不再主动停用整个运行层。常态使用原生资源，交互通过透明层显示。
- 修正 示例光标主题 点按/松手资源末尾约 60 秒的冻结帧，保留实际动作时长。

## 已知问题

- macOS 原生光标切换后，水平调整识别、后台点按与未知→已知恢复仍可能失败。**这部分未宣告修复**，已记录在 [Issue #1](https://github.com/Dannincaren/Gallery/issues/1)，按要求延后处理。
- 出现卡住或不响应时，可从菜单栏「停用并恢复」后重新应用；仍异常则退出并重开 Gallery。
- 独占游戏、自绘光标、安全界面及所有 macOS 版本的兼容性未验证。
- 待机目前播放循环片段；独立进入/退出段和拖窗专用动画暂未接入。

## 下载与使用

下载 `Gallery-macOS.zip`，解压后将 Gallery 放入「应用程序」，先退出旧版再打开。
支持 macOS 14+，包内包含 Apple Silicon 与 Intel 架构；应用使用临时签名，尚未签名公证。

打开应用后选择「导入主题」，导入已整理的 `.gallery` 文件，然后点击「应用主题」。
原始素材不随应用或源码分发；也可在应用内导入自己下载的完整 示例光标主题 Windows ZIP。
