# Gallery — macOS 动态鼠标指针与主题编辑器

为 Mac 更换鼠标指针，播放常态、待机、按下、按住和松手动画；直接导入 Windows 光标主题，在应用内调整热点、大小和帧序列。

[下载最新版](https://github.com/Danningcarer/Gallery/releases/latest) · [English](README.md) · [反馈问题](https://github.com/Danningcarer/Gallery/issues/new)

**macOS 14+，Apple 芯片与 Intel；公开源码，非商业许可。**

## 快速开始

1. 在 Releases 下载 `Gallery-macOS.zip`，解压后把 `Gallery.app` 放到「应用程序」。
2. 点击右上角 **＋**，选择主题、CUR／ANI、INF、文件夹、ZIP 或支持的 EXE。含多套素材时先勾选需要的内容，可按需预览。
3. 单击卡片选中主题，点 **▶** 使用。再次点已选中或正在使用的卡片进入编辑；点 **⏸** 停用并恢复。关闭窗口后仍可从菜单栏控制。

内置主题由本项目绘制，不需要先下载第三方素材。正在使用的主题暂停后才能编辑，其他主题可直接修改。

## 可以调整什么

- 常态、待机、按下、按住、松手片段，逐帧预览、复制、替换、排序与时长。
- 热点点选和数值输入；每个主题的整体大小、每个角色的独立大小，均支持 25%–300%。
- 各角色独立待机等待时间；有按住素材就持续播放至松手。
- 封面、主题排序、单角色混用另一主题或原生光标、导出和整套删除。
- 抗锯齿与柔和阴影；更改外观后异步重建封面和缩略图，橱窗始终静态。
- 登录自启动、启动后自动应用、隐藏 Dock 图标、甩动放大和应用排除。

## 导入文件

支持 `.gallery`、`.cape`、单独 CUR／ANI、带 CUR／ANI 的文件夹和 ZIP，以及有配套文件的 INF。支持读取部分 .NET、.NET 单文件、Inno Setup 和 ZIP 自解压 EXE。

**Gallery 仅读取 EXE 中的数据，不运行 Windows 程序。** 不同安装包的封装方式不同；请选择实际含素材的文件，不能解析的其他封装或加密包请先解压，再导入 CUR／ANI 文件夹。

ZIP 支持常用存储／Deflate、ZIP64、Unicode 和常见旧式中文文件名，校验长度及 CRC。安装包上限 2 GB，素材展开大小和数量另有限制；壁纸、应用图标等无关内容会被跳过。详细说明见[兼容格式与限制](Documentation/COMPATIBILITY.md)。

## 权限与恢复

「输入监控」用于只读鼠标事件监听，不记录键盘，不申请辅助功能权限。未开启时使用备用鼠标事件／计数路径，不同应用中的响应可能有差异。

应用启用前备份系统光标，正常停用或退出时恢复。强退或崩溃后可重新打开并恢复上次光标。不要同时运行其他自动重应用光标的软件。

私有系统接口存在 macOS 版本差异；部分应用自绘光标与安全界面可能仍显示原生光标。当前发布包为临时签名，尚未 Developer ID 公证。其他问题见[故障排查](Documentation/TROUBLESHOOTING.md)。

## 性能与开发

优先顺序为点按响应、CPU／能耗、体积；保留 macOS 管理的位置与合成，使用有界动画帧缓存。关闭或遮挡预览时停止播放，不持续刷新主题卡片。测量方法与结果见[性能记录](Documentation/PERFORMANCE-1.0.0.md)。

源码构建、命令行转换与检查入口见 [English README](README.md#build-and-test)。需 Xcode 26.2+ 或对应命令行工具，部署目标 macOS 14+。
